## Problem
ปัจจุบันการรับและกระจายเอกสารภายในองค์กรมีเอกสารเข้ามาจากหลายช่องทาง เช่น Email, Web Submission, Upload File และหน่วยงานภายนอก ทำให้เกิดปัญหาในการจัดการเอกสาร เช่น

- ผู้ส่งเอกสารไม่ทราบช่องทางและขั้นตอนที่ถูกต้องในการส่งเอกสาร
- ข้อมูลเกี่ยวกับประเภทเอกสารและรายละเอียดที่ต้องเตรียมไม่ชัดเจน
- การส่งต่อเอกสารระหว่างผู้เกี่ยวข้องหลายฝ่ายอาจเกิดความล่าช้า
- ไม่สามารถตรวจสอบกระบวนการดำเนินงานของเอกสารได้อย่างชัดเจน

ระบบ Electronic Mailbox & Document Flow System จึงถูกพัฒนาเพื่อช่วยจัดการกระบวนการรับ ลงทะเบียน ส่งต่อ และติดตามเอกสารอย่างเป็นระบบ โดยมีเป้าหมายเพื่อเพิ่มความถูกต้อง ความสามารถในการตรวจสอบย้อนหลัง (Traceability) และลดปัญหาเอกสารตกหล่น

## V1 Goal
V1 มุ่งเน้นการพัฒนา Information Service เพื่อให้ผู้ใช้งานสามารถเข้าถึงข้อมูลพื้นฐานเกี่ยวกับระบบรับและกระจายเอกสาร โดยยังไม่จำเป็นต้องเข้าสู่ระบบ

เป้าหมายของ V1 คือสร้างแหล่งข้อมูลที่ช่วยให้ผู้ใช้เข้าใจกระบวนการทำงานก่อนเริ่มใช้งานระบบจริง ได้แก่

ขอบเขตที่พัฒนาใน V1
- แสดงข้อมูลประเภทเอกสารที่ระบบรองรับ
  - หนังสือราชการ
  - บันทึกข้อความ
  - เอกสารจากคณะ
  - เอกสารภายใน
- แสดงช่องทางการรับเอกสาร
  - Email
  - Web Submission
  - Upload File
  - หน่วยงานภายนอก
- แสดงขั้นตอนการดำเนินงานของเอกสาร (Document Workflow)
